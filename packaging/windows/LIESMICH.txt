ScanToBIM fuer Windows (64 Bit)
===============================

Punktwolken & Fotos -> 3D-Modelle mit sauberen Kanten.
Keine Installation noetig: scantobim.exe ist eigenstaendig
(Python ist NICHT erforderlich).

Erster Start / Windows-Warnung "schaedlich"
-------------------------------------------
Windows SmartScreen warnt bei heruntergeladenen, nicht code-signierten
Programmen ("Der Computer wurde durch Windows geschuetzt" o. ae.).
Das ist normal fuer Open-Source-Software ohne (kostenpflichtiges)
Code-Signing-Zertifikat - die Datei kommt direkt aus dem oeffentlichen
GitHub-Build, der Quellcode ist einsehbar.

So verschwindet die Warnung DAUERHAFT:
  1. Zip-Datei ENTPACKEN (nicht aus dem Zip heraus starten!).
  2. Rechtsklick auf scantobim.exe -> Eigenschaften -> unten bei
     "Sicherheit" das Haekchen "Zulassen" setzen -> OK.
     (Das entfernt die Internet-Markierung der Datei.)
  Alternativ einmalig: "Weitere Informationen" -> "Trotzdem ausfuehren" -
  Windows merkt sich das pro Datei. Nach jedem Update (neue Datei)
  erscheint die Warnung einmal neu.

Grafische Oberflaeche (empfohlen)
---------------------------------
* Doppelklick auf scantobim.exe startet die grafische Oberflaeche
  im Browser (laeuft lokal auf diesem Rechner, kein Internet noetig):
  Punktwolke per Drag & Drop hineinziehen, Modus waehlen (Gebaeude /
  Maschinenbau & Stahl / Blech / Bruecke), "Modell erstellen" -
  3D-Viewer, Messbericht und alle Exporte erscheinen direkt dort.
* Punktwolken-Dateien im Explorer direkt AUF die scantobim.exe
  ziehen: die GUI startet mit diesen Dateien bereits geladen.
* Das Konsolenfenster dahinter ist das Protokoll - offen lassen,
  Strg+C beendet das Programm.
* Ohne Browser gewuenscht? "scantobim.exe wizard" ist der gefuehrte
  Konsolen-Modus.
* In der GUI: "Quelle/Scanner" waehlen (SLAM S20, Stativ-Scanner,
  Drohne, iPhone), unter "Erweiterte Einstellungen" feinjustieren
  (Erklaerung erscheint beim Draufzeigen mit der Maus) und alles als
  eigenes Profil dauerhaft speichern.

Benutzung (Eingabeaufforderung oder PowerShell)
-----------------------------------------------
  scantobim.exe --help

  :: Punktwolke inspizieren
  scantobim.exe info scan.laz

  :: GPU/CUDA-Diagnose (GPU-Version): schreibt gpu_diagnose.txt
  scantobim.exe gpu

  :: Gebaeude/Raum -> Modell (interaktiver Viewer, einfach im Browser oeffnen)
  scantobim.exe reconstruct scan.laz -o modell.html --texture

  :: CAD- und BIM-Export
  scantobim.exe reconstruct scan.laz -o modell.stp
  scantobim.exe reconstruct raum.e57 -o modell.ifc --preset indoor

  :: Grundriss als DXF (mit automatischer Wand-Bemassung)
  scantobim.exe reconstruct scan.laz -o modell.glb --floorplan grundriss.dxf

  :: Qualitaetssicherung: Soll-Ist-Abweichung + massstabsgetreue Ansichten
  scantobim.exe reconstruct scan.laz -o modell.html --deviation qa.ply --views ansichten

  :: Selbstoptimierend + druckfertiger Pruefbericht
  scantobim.exe reconstruct scan.laz -o modell.html --preset auto --report-html pruefbericht.html

  :: Verformungsmonitoring: zwei Aufnahmen desselben Objekts vergleichen
  scantobim.exe compare epoche1.e57 epoche2.e57 -o verformung.json --heatmap verformung.ply

  :: Maschinenbau: Wellen, Zahnraeder, Getriebe, Stahlprofile, Anschluesse
  scantobim.exe analyze getriebe.e57 -o analyse.json --mesh primitive.glb

  :: Geschweisste Blechkonstruktionen: Dicken, Naehte, Brennschnitt-DXF
  scantobim.exe sheetmetal behaelter.ply -o bleche.json --dxf zuschnitt.dxf

  :: Brueckenbauwerke: Typ, Felder, Pfeiler, Lager, Bogen, Seile
  scantobim.exe bridge bruecke.laz -o bauwerk.json

  :: SLAM-Scanner-Projektordner (z. B. SHARE SLAM S20): Punktwolke,
  :: Fotos, Kameraposen und Trajektorie werden automatisch erkannt
  scantobim.exe project D:\scans\projekt_export -o modell.html

  :: Mehrere Scans registrieren und verschmelzen
  scantobim.exe register standpunkt1.ply standpunkt2.ply -o gesamt.ply

Eingabeformate:  .las .laz .e57 .ply .pcd .pts .xyz .csv  (+ Fotos via COLMAP)
Ausgabeformate:  .stp .ifc .glb .obj .stl .html .dxf + JSON-Berichte

Hinweis Foto-Workflow: "scantobim.exe photos" benoetigt ein separat
installiertes COLMAP (https://colmap.github.io). Alternativ die dichte
Punktwolke aus einem beliebigen Photogrammetrie-Programm als .ply laden.
